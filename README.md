# Python Sales Data Visualization

## Project Overview
This project explores pharmaceutical sales data using Python to compare sales performance across regions, customer tiers, states, divisions, and quarters for 2015 and 2016.

## Objectives
- Compare regional sales across two years.
- Visualize each region's contribution to 2016 sales.
- Analyze sales by region and customer tier.
- Identify states and divisions with declining performance.
- Compare quarterly sales and customer-tier composition.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Project Files
- `Sales_Visualization_Case_Study.ipynb` — analysis and visualizations.
- `SalesData(1).csv` — source dataset.

## How to Run
1. Download the notebook and CSV.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Update the dataset path if necessary.
5. Run the notebook cells.

## Key Learning Outcomes
- Data aggregation and reshaping with Pandas.
- Comparative bar charts and pie charts.
- Regional and quarterly sales analysis.
- Data visualization for business insights.
